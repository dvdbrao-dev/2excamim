# Requirements

## Rust

Desde la raíz del repo:

```bash
cargo fmt
cargo check
cargo test
```

## Prediction Markets Research Dependencies

Python:

- python3
- python3-venv
- requests
- pandas
- pyarrow

Instalación recomendada:

```bash
python3 -m venv research_prediction_markets/.venv
source research_prediction_markets/.venv/bin/activate
pip install requests pandas pyarrow
```
